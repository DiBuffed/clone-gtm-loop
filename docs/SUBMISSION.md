# Clone Loop Day 제출 문안

제품: 요리GO https://yorigo.kr/
Repo: https://github.com/DiBuffed/clone-gtm-loop

SNS 요리 영상을 저장하지만 다시 찾고 재료를 정리하는 번거로움 때문에 실제 요리로 옮기지 못하는 고객을 대상으로 합니다.

공개 불편 신호 조사 → 원문/최근성/제품 적합성 바이너리 판정 → 타깃·가상 페르소나 설계 → AI 리액션 3초 생성 → 실제 앱 시연·CTA 합성 → Instagram 배포 → 실제 신규 활성 관측 → 다음 조사·훅 개선을 연결했습니다.
진행자의 외모를 고객 데이터로 오인하지 않고, 같은 고객에서 훅을 바꿀 때는 페르소나와 시연을 재사용합니다.
`/gtm/loop`에서 각 단계의 근거와 결과를 직접 열어볼 수 있습니다.

10월 31일 오후 6시까지의 목표:
- 캠페인에 귀속된 신규 적합 활성 사용자 20명
- 실제 게시 영상 7개
- 실제 관측 근거를 남긴 반복 학습 3회 이상
- 독립 원문의 적합 고객 신호 20건
- 검증된 제휴 구매·매출은 별도로 보고

활성화는 신규 적합 사용자의 자기 레시피 생성 후 24시간 내 저장으로 고정합니다.
조회/클릭/설치/구매를 구분하며, 테스트 리플레이는 실제 트랙션에 포함하지 않습니다.
운영 연결이 완료되지 않은 항목과 기준선 미확인 값은 명시적으로 표시하고, 7일간의 개선 이력과 목표 대비 결과를 저장하겠습니다.
